# Day 01 - JavaScript Basics for Playwright

## Objective

Learn the JavaScript fundamentals required for Playwright automation.

## Concepts Covered

- Variables
- `let`
- `const`
- Strings
- Numbers
- Booleans
- Functions
- Function parameters
- Return values
- Arrays
- Objects
- Array of objects
- Template literals
- Basic assertions

## Practical Exercises

### 1. Variables
Created QA-related variables using `let` and `const`.

### 2. Functions
Created a reusable function to calculate total test cases.

### 3. Arrays and Objects
Created testing tool arrays and tester information objects.

### 4. Login Test Data
Created an array of objects representing positive and negative login scenarios.
